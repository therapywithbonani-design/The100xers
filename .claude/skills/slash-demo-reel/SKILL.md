# Slash Demo Reel (STYLE: SLASHDEMO)

Source: 26s reel. Dark mobile chat UI (Chat | Code toggle), creator types `/effects glass-widgets`, `/effects documentary`, `/effects orbit`, `/effects kallaway-split`, `/effects spotlight`, `/effects checklist`, `/effects timeline` → each renders → full-screen result. Ends: "Comment 'claude' for all 36 effects" grid.

## Beat per effect (≈3.3s)
| Time | What you see | Edit detail |
|---|---|---|
| 0.0–0.8 | Chat screen; `/` typed → **autocomplete menu** (/effects "36 video effects for your clips", /init, /review); then name typed, a sub-menu chip shows the effect + one-line description ("orbit — your reels circle your head") | Real screen-record or rebuilt UI; iOS keyboard with **key-pop bubbles** on each tap; command text in orange #E8734A |
| 0.8–1.2 | Message sent: thumbnail + command bubble right-aligned; status line "✳ Editing with orbit…" | Bubble slide-up 4f |
| 1.2–1.8 | Chat card shows **pixel-dot dissolve**: black card filled with orange/white dots that resolve into the edited clip | Pixel mosaic 40px→0 over 12f (see built-in `reel-pixel-reveal`) |
| 1.8–2.2 | Edited clip plays inside the chat card | — |
| 2.2–3.3 | **Hard zoom to full screen** result (UI disappears) | Scale card 55%→100% in 4f, then hold |
Next effect: hard cut back to the chat screen.

## Visual system
- UI: background #262624, input field #30302E rounded 18px, white text, orange accent #D97757 (send button, command text, status asterisk).
- Font: system sans (SF Pro / Inter) for UI; mono not used.
- Keyboard visible during typing beats (sells "I just typed this").
- Captions: none — the command name IS the caption.

## Ending CTA (last ~4s)
1. New chat: greeting "✳ Evening, [Name]" (serif); user types **claude** → bubble.
2. Reply streams: "Comment "claude" and I'll send you all 36 effects".
3. Pixel dissolve → **grid card**: "Comment "claude"" (white bold) + orange pill "for all 36 [Brand] effects", 5×4 numbered thumbnails (orange number badges, `/name` labels in mono at the bottom of each) + last tile "+17 more effects".
4. Card zooms to full screen; hold 2s.

## Adapt for clients
- Agency capability reel: `/edit luxe`, `/edit podcast`, `/edit lookbook` → each client result → "Comment EDIT for the full menu".
- D2C brand: `/style office`, `/style party`, `/style wedding` → outfit results → "Comment LOOKS".
- Café: `/order matcha`, `/order cold brew` → product shots → "Comment MENU".
- Real estate: `/tour 2BHK`, `/tour villa` → walkthrough clips → "Comment BROCHURE".

## Conversion
Comment-keyword → auto-DM with the full list/menu/brochure → lead capture. KPIs: keyword comments per 1k reach, DM opt-in %, CPL, replay rate.
